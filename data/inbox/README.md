# 買取表画像の置き場

トレカマサイ（[@ttt_kaitori](https://x.com/ttt_kaitori)）の BOX 買取表の画像を
**ここに置いてコミットする**。毎日の取り込みジョブがここを見る。

## ファイル名

```
YYYY-MM-DD_ttt_kaitori.jpg
```

日付は**買取表が投稿された日**。同じ日に複数枚あるなら連番を付ける。

```
2026-09-11_ttt_kaitori_1.jpg
2026-09-11_ttt_kaitori_2.jpg
```

ファイル名がそのまま観測の `source` になる。取り込み済みかどうかは
`data/box_prices.jsonl` の `source` と突き合わせて判定するので、
**取り込んだあとも画像は消さないこと**（消すと二重取り込みの判定ができなくなる）。

## 未取り込みの確認

```bash
python3 -m pokebox_ev box-pending
```

## なぜこの方式か

実行環境のネットワークポリシーが x.com を遮断しているため、
ツイートの画像を直接取得できない。画像ファイルとして置いてもらえれば
中身を読んで数値を抜き出せる。

対応形式: `.png` `.jpg` `.jpeg` `.webp`
