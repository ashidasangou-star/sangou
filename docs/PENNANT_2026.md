# 阪神タイガースの優勝確率（2026年9月18日終了時点）

## 結論

**67.3%**（モンテカルロ誤差 ±0.15pt、40万回試行）。

| チーム | 現在 | 残り | 優勝確率 |
| --- | --- | --- | --- |
| 阪神 | 71勝57敗1分 .555 | 14 | **67.3%** |
| 巨人 | 71勝59敗2分 .546 | 11 | 32.6% |
| DeNA | 65勝64敗3分 .504 | 11 | 0.1% |
| ヤクルト / 広島 / 中日 | — | — | 0%（数学的に消滅） |

仮定を動かしても **65〜69%** の範囲に収まる（後述の感度分析）。
「1ゲーム差で首位、しかも直接対決に16勝8敗」という状況は強いが、
巨人より3試合多く残っているぶん、取りこぼしの機会も3試合多い。
2/3 という数字はそのトレードオフの結果である。

## 現状の整理

143試合制。順位は **勝率 = 勝/(勝+敗)** で決まり、引き分けは分母に入らない。
勝率同率の場合は (1) 勝利数 (2) 当該球団間の対戦成績 の順で上位を決める。

- 阪神は129試合を消化して残り14。巨人は132試合消化で残り11。
- 直接対決は阪神の16勝8敗。**残りは10月1日・甲子園の1試合だけ**。
  つまり勝率が並んだ場合の対戦成績比較は、最後の1戦の結果によらず阪神が上。
  同率決着は実質「阪神の優勝」を意味する。
- 阪神が残り全敗しても .500（71勝71敗）。この下限を上回れないヤクルト（最高 .493）、
  広島（.486）、中日（.461）はこの時点で優勝の可能性が消えている。
  DeNAだけは最高 .543 なので数学的には残っているが、実質ゼロ。

## 何をどう計算したか

やっていることは3段階しかない。

### 1. 「今の勝率」をそのまま使わない（実力のベイズ推定）

130試合の勝敗には無視できない量の偶然が乗っている。勝率 .555 の標準誤差は
1試合あたり `sqrt(0.25/128) ≈ .044` もあり、`.555` と `.546` の差（.009）は
誤差の 1/5 でしかない。**標本勝率をそのまま残り試合に外挿すると、首位チームの
優勝確率は必ず過大に出る。**

そこで各チームに潜在的な強さ θ を置く Bradley–Terry モデルを使う。

```
P(i が j に勝つ | 引き分けない) = logistic(θ_i - θ_j + h)
```

θ には階層事前分布 `θ_i ~ N(0, σ²)` を与え、σ（リーグ内の実力の散らばり）自体も
データから推定する。σ を固定せずに推定させるのがこの手の予測でいちばん効く。
σ の事前分布は過去のNPBの最終順位の散らばり（勝率 sd .03〜.08、そこから
二項ばらつきを除いた実力 sd は .03〜.06、`dp/dθ = 0.25` なので θ では 0.12〜0.24）
から、中央値 0.18 の対数正規分布とした。

推定は乱歩メトロポリス法（MCMC）。パラメータは7個しかないので標準ライブラリで足りる。

交流戦は別扱いにした。2026年はパ・リーグの65勝39敗4分で、セ全体が18試合ずつ
大きく負け越している。これをセ内部の実力差と取り違えないよう、パ・リーグ平均を
仮想チーム θ_PL として明示的に持ち、その事前分布を交流戦の通算成績
`log(65/39) = 0.511`（標準誤差 0.196）から直接与えている。

結果（対リーグ平均・中立球場での期待勝率）:

| チーム | 実績勝率 | 推定 θ | 推定勝率 |
| --- | --- | --- | --- |
| 阪神 | .555 | +0.12 | .531 |
| 巨人 | .546 | +0.10 | .527 |
| DeNA | .504 | +0.04 | .509 |
| ヤクルト | .445 | −0.06 | .483 |
| 広島 | .425 | −0.10 | .475 |
| 中日 | .424 | −0.10 | .474 |

実績ほど極端ではない方向に縮む（縮小推定）。これが正しい。**阪神と巨人の
実力差は、推定するとほとんど無い。** 優勝確率の差はほぼ「1ゲームのリード」と
「残り試合数の違い」だけで説明される。

### 2. 残りのシーズンを最後まで再生する（事後予測モンテカルロ）

強さの点推定を1つ決めて回すのではなく、事後分布から θ を引き直しながら
シーズンを再生する。こうすると「どのくらい強いか自体わからない」という
不確かさまで確率に乗る（点推定で回すと確率は極端に出る）。

1試合の生成規則:

```
引き分け      : 確率 τ = 1.5%（今季の発生率）
ホームの勝ち  : (1-τ) × logistic(θ_home - θ_away + h),  h = 0.14（本拠地勝率 .535 相当）
ビジター勝ち  : 残り
```

引き分けは「勝率据え置きで残り試合が1つ減る」効果を持ち、**リードしている側に
有利**に働く。この非対称性も数え上げに入っている。
阪神・巨人・DeNAの残り試合を日付順に再生し、順位決定規定に従って優勝チームを決め、
40万回ぶんの頻度を確率として読む。

### 3. 出てきた数字

外部の公開モデル（Elo ベースのサイト）が9月17日時点で阪神 68.1% としており、
独立に組んだこのモデルの 67.3%（9月18日時点）とほぼ一致する。

読みどころは2つ。

- **10月1日の巨人戦だけが別格**。勝敗で優勝確率が 30pt 動く（81.2% ↔ 51.1%）。

  他の13試合はどれも 14〜15pt で、価値はほぼ等しい。
  「この試合は大事」と言えるのは事実上この1試合だけ。
- **引き分けは負けよりずっと良く、勝ちよりわずかに悪い**（例: 9/19 は 70.7%、

  引き分けは「消化試合が1つ減る」ので、価値としては勝ちの8割前後ある。

## 残り何勝すれば優勝できるか

| 残りの勝数 | そうなる確率 | そのときの優勝確率 |
| --- | --- | --- |
| 4勝 | 3.9% | 7.1% |
| 5勝 | 8.9% | 19.9% |
| 6勝 | 15.2% | 40.3% |
| 7勝 | 19.6% | 64.1% |
| **8勝** | 20.1% | **83.7%** |
| 9勝 | 15.6% | 94.9% |
| 10勝 | 9.4% | 99.1% |
| 11勝 | 4.1% | 99.9% |
| 12勝 | 1.2% | 100%（マジック対象と無関係に確定） |

**8勝6敗**（.571）まで行けば8割方優勝。**7勝7敗の五分**だと 64%。
6勝8敗に落ちると 40% を切る。実用的な目標ラインは「残り14試合で8勝」。

なお9月18日終了時点の優勝マジックは **12**。これは「12勝すれば巨人の結果に
関係なく優勝が確定する」という数字であり、上の表で12勝が 100% になっているのと
一致する。ただし実際には8勝前後で決まる可能性が高い。

## 感度分析

仮定を動かしたときに答えがどれだけ動くか。

| 仮定 | 阪神の優勝確率 |
| --- | --- |
| **基準** | **67.3%** |
| 実力差が小さい（σ=0.10固定） | 66.4% |
| 実力差が大きい（σ=0.25固定） | 68.9% |
| 本拠地補正なし（h=0） | 67.6% |
| 本拠地補正2倍（h=0.28） | 67.0% |
| 引き分けなし（τ=0） | 67.0% |
| 引き分け3% | 67.4% |
| 残り日程の相手が強い側にぶれた場合 | 65.9% |
| 残り日程の相手が弱い側にぶれた場合 | 69.1% |

**どの仮定を動かしても 65〜69%**。結論は仮定に対して頑健である。
これは阪神と巨人の推定実力がほぼ互角で、結果がモデルの細部ではなく
「1ゲーム差・残り14 vs 11・直接対決1試合」という構造で決まっているため。

このモデルが**見ていない**もの:

- 先発ローテーションの並び、故障者、疲労、残り試合の連戦日程
- 直近の調子（シーズン全体の成績を等しく扱っている。直近重視にしても
  両チームの推定実力が近いため結論はほとんど変わらない）
- 消化試合になった球団の主力温存
- クライマックスシリーズ・日本シリーズ（ここで出しているのは**リーグ優勝**の確率）

## 再現・更新の方法

```bash
python3 -m npb_pennant                          # 既定データで計算
python3 -m npb_pennant --sensitivity            # 感度分析つき
python3 -m npb_pennant --assume WWL             # 直近3試合が勝勝負だった場合
python3 -m npb_pennant --json                   # 機械可読な出力
```

`--assume` は阪神の残り試合に先頭から順に結果を当てはめる（W=勝 / L=敗 / T=分）。
相手チームの勝敗と直接対決の成績も同時に更新されるので、
**試合が終わるたびに1文字足して再実行すれば、その時点の優勝確率が出る。**
巨人や他球団の結果も反映したい場合は `data/npb_2026_central.json` を直接更新する。
